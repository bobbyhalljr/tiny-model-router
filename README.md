# tiny-model-router

Tiny TypeScript model router. Picks the cheapest model that fits each task, honors overrides, and pauses work at a per-project spend cap. No API key. No network.

```bash
npm install
npx tsx router.ts
```

Example output is in `output.txt`. All inputs are made up. This is a small teaching model, not any vendor's implementation.
